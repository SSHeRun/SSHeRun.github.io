## 本章要义

CPU 快、磁盘慢，中间用 cache 和主存做层次。cache 解决「正在用的那一小团」，虚拟存储器解决「程序以为自己有很大的连续空间」。两者都靠局部性。

```mermaid
flowchart LR
    VA[虚地址] --> MMU[MMU / TLB]
    MMU --> PA[物理地址]
    PA --> CACHE[Cache]
    CACHE -->|缺失| MEM[主存]
    MEM -->|缺页| DISK[辅存]
```

直接映射看行号，组相联看组号。TLB、页表、cache 是三张不同的表。

## 源笔记勘误

- 写策略列了「标志交换（写回）」「通过式写入（写通）」之后，又来一句「写操作直接对主存进行，而不写入 cache」。那是 **write-around / 写非分配**，不是第三种一致性协议，被平级罗列就乱了。
- 平均时间 \(h\cdot t_c+(1-h)(t_c+t_m)\) 假定 miss 时先查 cache 再访主存（且主存返回后不再加一次 \(t_c\) 写 cache，或把写 cache 算进 \(t_m\)）。另一种写法是 \(t_c+(1-h)t_m\)。题面给不给「失败也先访问 cache」要看清。
- 「最好替换策略」只说了一句理想：替换未来最久不用的块（OPT）。实际用 LRU / FIFO / 随机。
- 虚存只写了两句特点，没有页表、TLB、缺页。这和操作系统第五章重叠，组成课至少要会虚实地址怎么切。
- 源笔记没有辅存细节的交叉引用；磁盘参数在下一章。

> 交叉链接：操作系统里的虚拟内存见 `os` 学科。在对应章节写完之前，先把组成侧的地址变换看懂。

## cache

CPU 给出主存地址，先看 cache 有没有这块。

- **直接映射**：每个主存块只能进一个 cache 行。地址 = 标记 + 行号 + 块内。冲突多，硬件简单。
- **全相联**：块可进任一行。灵活、比较器多。
- **组相联**：先按组号定位一组，组内全相联。是折中。地址 = 标记 + 组号 + 块内。

写策略：

- **写直达（write-through）**：写 cache 同时写主存。一致性简单，写带宽大。常配写缓冲。
- **写回（write-back）**：只写 cache，换出脏块才写主存。要脏位。
- **写分配 / 非写分配**：miss 时要不要把块调进 cache。写回通常写分配；写直达可非写分配（源笔记那句「不写入 cache」属于这里）。

替换：LRU 近似最优；直接映射无替换选择。

命中率 \(h\) 受容量、块长、相联度、程序局部性影响。块太长会有无用数据，太短则标记开销大。

## 虚拟存储器

程序用虚地址，MMU 译成主存物理地址。有辅存不一定是虚存：虚存的要点是**每次访存都做地址变换**，且允许程序空间大于主存。

页式（组成课最常考）：虚页号 + 页内偏移。虚页号查页表得物理页号，偏移不变。页表在主存，所以再加 **TLB** 缓存近期变换。TLB miss 再查页表；页表说不在主存就缺页，向辅存调页（这是 OS 的工作）。

段式、段页式知道「段有界限检查、段页先段后页」即可。

## 408 易错点

- 组相联的「组号」来自地址中间字段，不是操作系统的进程组。
- cache 标记比较的是块号高位，不是整个地址。
- 写回 miss 若要换出脏块，实际时间还要加上写回主存。
- TLB、页表、cache 是三张不同的表，不要画成一层。

## 考研题精练

**题 1（cache 映射）**  
cache 采用直接映射，共 64 行。主存第 200 块应映射到 cache 的第（ ）行。

A. 8 B. 16 C. 36 D. 200

**解答：** 直接映射行号 = 块号 \(\bmod\) 行数，\(200 \bmod 64=8\)。**选 A。**

**题 2**  
关于 cache 写策略，下列叙述正确的是（ ）。

A. 写回法每次写 cache 都同时写主存  
B. 写直达法必须设置脏位  
C. 写回法只在换出脏块时才写主存  
D. 写非分配是第三种与写回、写直达并列的一致性协议

**解答：** 写回靠脏位，命中只改 cache。写非分配描述的是 miss 时调不调块，常与写直达搭配，不是第三套一致性。**选 C。**

**题 3**  
cache 命中率 \(h=0.9\)，命中时间 \(t_c=2\,\text{ns}\)，缺失惩罚 \(t_m=20\,\text{ns}\)（不含已花费的 \(t_c\)）。平均访问时间是（ ）。

A. 2 ns B. 4 ns C. 18 ns D. 22 ns

**解答：** \(t_{\text{avg}}=t_c+(1-h)t_m=2+0.1\times 20=4\,\text{ns}\)。若写成 \(h\cdot t_c+(1-h)(t_c+t_m)\) 也是 4 ns。**选 B。**
