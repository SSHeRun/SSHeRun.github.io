知乎封了人，楼主跑来 V2EX 问：你们怎么看出来的？

帖子本身不稀奇，稀奇的是楼里几乎一边倒——不是在争论「有没有水印」「哪家检测器准」，而是在拆一件事：**中文 AI 味长什么样**。检测器分数常与人的语感打架；更稳的信号是句式模板、假真诚结构、情绪缺席，以及「正确废话 + 软广植入」。

来源：[V2EX #1254605](https://www.v2ex.com/t/1254605)

## 一个打脸样本

![中文环境下如何识别 AI 语句概览](../../assets/inline-spot-ai-writing-in-chinese-01.jpg)

楼主贴出一段「读英文原著体会」，自称只改了几个字。朱雀 AI 给出：人工 99.6%、AI 0.4%。

评论区几乎一致：一眼 AI。

| 谁说的 | 结论 | 说明 |
|---|---|---|
| 朱雀检测器 | 人工 99.6% | 与楼里语感打架 |
| 评论区 | 一眼 AI | 句式、假真诚、软广结构 |
| 后半段文本 | BookYell 说明书味 | 痛点铺垫 → 功能罗列 →「比如」新产品名 |

更糟的是，后半段被拆成产品说明书；楼主还用「我们核实一下」「我们维护一下」回应版本问题，推广属性基本坐实。

真正结论：**用户真正讨厌的，往往是 AI 味营销，而不只是「用了 AI」。**

## 语感派：哪些句子会立刻露馅

![假金句与正确废话的氛围](../../assets/inline-spot-ai-writing-in-chinese-03.jpg)

楼里高频击杀信号，几乎都能在这段样本里找到：

| 信号 | 样本味示例 | 为什么像 AI |
|---|---|---|
| 转折无对象 | 「但不骗人」——但什么？ | 模板转折，缺上文锚点 |
| 奇怪搭配 | 「收获是长在身上的」 | 病句感，不像人话 |
| 过工整结构 | 首先语感、其次文化、总之别当任务 | 作文范文体 |
| 情绪过克制 | 「怀疑人生」「差点放弃」贴标签 | 说明书里的情绪贴纸 |
| 主谓宾过齐 | 句句语法完整 | 真人常缺主语/谓语 |
| 书面口语硬混 | 「怎么用词……」接「学不来」 | 两种语域硬焊 |

还有一个很毒的观察：读完「很震撼」，却复述不出任何一个具体新知识——那就是 aislop。金句密度过高时，金句本身就贬值了。

## 口癖清单：中文 AI 的高频句式

社区反复点名的「拖出去」句式：

| # | 口癖 | 为什么可疑 |
|---|---|---|
| 1 | 「不是……而是……」连环对举 | 假辩证，信息量常为零 |
| 2 | 「真正稀缺 / 真正值得警惕的从来不是……」 | 正确废话起手式 |
| 3 | 「一句话说清楚」「翻译成人话」「这才是我真正想说的」 | 自我加戏 |
| 4 | 「下面从 X 方面为你拆解」 | 课件腔 |
| 5 | 「底层逻辑」包装正确废话 | 名词升维、内容不升维 |
| 6 | 少用「可能 / 大概 / 我感觉」 | 缺真人不确定语气 |

有人整段戏仿 aislop，把「不是 AI 太像人，而是太多人写得像 AI」写到夸张——读着爽，却什么也没学到。这正是识别器：你被牵着鼻子走，口袋里却没留下新事实。

## 检测工具为什么不可靠

![中文环境下如何识别 AI 语句细节](../../assets/inline-spot-ai-writing-in-chinese-02.jpg)

楼里推过朱雀、扫描全能王、自研识别器。同一段文字，有人测出几乎全人工，有人测出 100% AI。

| 手段 | 有用处 | 别神话 |
|---|---|---|
| 单点检测分数 | 粗筛 | 与语感常打架 |
| 细粒度结构 | 三段枚举 + 推销交互 + 默认举例 | 比总分稳 |
| 不可见字符 / 水印 | 存在 | 编辑后易失效 |
| 草稿历史 | 一次粘贴 vs 逐步改 | 有时比模型分更有信息 |
| 平台折叠 | 可能是举报 | 真人也有误伤 |

细粒度分析更有用：三段式枚举 + 推销式交互 + LLM 默认举例（《老人与海》出现频率高得可疑）→ 更像「AI 生成 + 人工轻改软文」。真人如果真啃过某本书，通常会说卡在哪一章、读到第几页放弃，而不是只扔一个经典书名。

## 可操作识别清单

![审核与语感对照的氛围](../../assets/inline-spot-ai-writing-in-chinese-04.jpg)

### 句式与结构

| 查什么 | 红旗 |
|---|---|
| 对举 | 「不是 X，而是 Y」连环，假金句过密 |
| 收尾 | 「总之……」「首先……其次……」 |
| 课件腔 | 「下面从 X 方面拆解」；乱加「一句话 / 真正有价值」 |
| 排版 | 段落过工整、句子信息平铺 |

### 用词与搭配

| 查什么 | 红旗 |
|---|---|
| 比喻 | 奇怪 / 病句感 |
| 语域 | 书面语与口语硬混 |
| 转折 | 无对象 |
| 情绪 | 过度克制；缺少模糊词 |
| 语法 | 主谓宾过完整 |
| 举例 | LLM 默认经典书名，缺具体卡点 |

### 内容策略信号

| 查什么 | 红旗 |
|---|---|
| 信息残留 | 读完很震撼，复述不出新知识 |
| 软广语序 | 痛点铺垫 → 产品功能说明书 |
| 植入 | 「比如」后接读者不熟的新产品名 |

### 操作层

- 多读前 AI 时代文字，练语感  
- 短文难认；长文几乎总有味  
- 自用 AI 写完先搁几天再看  
- 看草稿是多次迭代还是一次性粘贴  

反例也要记住：人可以故意写出 AI 味；AI 经认真改写后局部特征会失效；检测器与水印都不是银弹。

## 对我有用的三件事

| 角色 | 动作 |
|---|---|
| 内容 / 产品文案 | 注入具体经历、残缺口语、真实不确定；避开「不是而是 + 假金句 + 软广」 |
| 鉴伪 / 审核 | 规则特征 + 软广结构 + 人审，别押单点分数 |
| 平台叙事 | 用户讨厌的常是电子潲水营销，不是工具本身 |

检测永远是概率。真正稀缺的，不是「判出是不是 AI」，而是还能不能写出带体温的句子——以及读者还愿不愿意信你。
