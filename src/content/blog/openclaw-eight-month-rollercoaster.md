## 核心观点

OpenClaw 不是「又一个 Agent 框架故事」。它是一个**八个月从厨房 WhatsApp 中继冲到全球关注、再被安全叙事与配置爆炸拖进谷底**的产品周期压缩包。

带走三句就够：

1. **产品可被 fork，你的名字不能**——个人品牌要在需要之前建立。  
2. **你依赖方的商业模式，就是你的商业模式**——模型订阅一断，路线图跟着断。  
3. **别停止享受乐趣**——乐趣是速度；不享受的几周，往往只在堆配置项。

## 对照：美团「养虾」vs Peter 的直觉

InfoQ 先放了企业侧镜头：2026 年 2–3 月美团全员引入 OpenClaw，热情高、账单也高（日耗上千万元量级），谬误开始干扰经营。王莆中把这段定义为 AI 转型第一阶段——AI 塞进日常事务却未碰核心业务，流程、组织、技术没同步改；折腾到 7 月才靠赛马跑出可用场景。

企业结论偏「系统工程，急不得」。Peter 的结论偏「相信直觉，修那个让你恼火的东西」。两者不打架：**一个讲落地阶段，一个讲起步燃料**。把开源个人玩具直接塞进上市公司经营，缺的是边界与治理，不是安装手册。

## 起源：被惹恼写出来的产品

灵感通常是恼火。一个下雨天，他想从手机盯着本机 agent，却没有干净通路——一小时后 WhatsApp 中继诞生。魔法不在「终端能聊」，而在**感觉**：简洁回复、主动找你、像朋友；模型、上下文、会话切换的复杂度被融化掉。

Twitter 推不动 → 拉朋友进群聊 → 非技术朋友想要、甚至对「还不给你用」生气——这是强 PMF 信号。Discord PR 把单通道中继变成多平台（命名从 ClaudeAss 一路蜕到 OpenClaw）。跨年夜公开构建；launch daemon 在 Ctrl+C 后自动重启，醒来八百条消息——差点被黑，也真正爆火。

八个月里：上万人提 issue/PR，数千人有提交；Mac Mini 卖断货；他自己差点删掉整个项目。教训很直白：**小心你许的愿。**

![从个人中继到公开构建](../../assets/inline-openclaw-eight-month-rollercoaster-02.jpg)

## Hermes、安全与 9500 个配置项

对手在最痛处赢：安全报告洪流 + 媒体「20% Skill 恶意」叙事（他们扫描约 6.7 万 Skill，真实比例更接近 0.3%）。辟谣永远跑不过恐慌。

他一层层加固：沙箱、白名单、权限、连符号链接与原子写配置都抠细节。多数用户喜欢「安全」这个抽象词，却恨更新后变慢、旧用法坏掉、升级变难。功能最好玩——一个 prompt 的距离；真正的成本在后面：每个功能拖来配置选项，高峰约 **9500 项**。有用户的软件，进化难度是无限倍。

更致命的一刀来自依赖方：Harness 长期为 Opus 优化得最好，Anthropic 约提前 24 小时通知禁用订阅——掉头时间不够。记下来：

**你依赖方的商业模式，就是你的商业模式。**

下载量像天气：5 月周下载跌到约 83.5 万谷底；6 月「被宣告死亡」后反而冲到约 470 万高点。炒作你控不住，只能决定风暴里修什么。

## 乐趣丢了，产品也就丢了

大约 2 月起，它不再有趣。他停止使用自己的产品，变成修 bug、修安全、搭基建、应付媒体与律师的人——「为所有人」杀死了「为我」。NVIDIA 很早就问「你需要什么」，并派人扛了大量安全工作。约 5 月生日前后，乐趣回来：恼火于不能直接让 agent 改软件，再次变成构建动力。

开源杀手故事讲不透本质：**开源**。很难打败一个只是在享受乐趣的人。

## 下一步与可执行清单

定位仍清楚：实验室卖给你一个 agent；OpenClaw 是替代方案——开源、随处跑、兼容任意模型，本地模型则可让数据不出设备。团队侧在做可见彼此会话、可接管编排的协作；产品侧走向语音与多模态（比如 FaceTime hack）。

对我（以及做 Agent 工具的人）更有用的检查项：

- **用户一号是自己吗？** 2–20 号是朋友；自己不兴奋，别指望市场兴奋。  
- **有没有 vision.md？** 敢不敢拒第 N+1 个「很酷但带偏方向」的 PR？  
- **安全边界划清了吗？** 哪些保证、哪些本就不是产品承诺——别把路线图交给未验证报告。  
- **Harness 是否绑死单一订阅？** 开放权重与多模型是生存能力，不是锦上添花。  
- **配置是否在爆炸？** 为兼容而加的开关，往往是乐趣与可维护性的税。

活在未来，构建缺失的东西；当他们写你的讣告时，继续发版——让他们困惑。
