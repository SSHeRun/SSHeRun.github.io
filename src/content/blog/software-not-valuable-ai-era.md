> 讨论来源：[AI 时代，软件已经不值钱了](https://www.v2ex.com/t/1238096)（V2EX）

## 核心观点

帖主说：纯软件很难再建立优势。社区多数会补一句——**贬值的是斩杀线以下的那一层**：人人都能 vibe 出来的工具壳、设置类、简单站。

我方把终局说得更狠一点：

> **未来 Agent 足够强，软件确实不值钱，甚至各种定制化也不值钱。**

功能会被默认能力吞掉；过去靠「改需求、改界面、改流程」收费的定制，会被「描述一下 → Agent 当场改」压成对话成本。还可能值钱的，是成果、责任、分发信任、专有数据与工作流记忆，以及硬件/资质这类软件 alone 碰不到的摩擦。

![软件货架与 Agent 编排隐喻](../../assets/inline-software-not-valuable-ai-era-01.jpg)

## 帖主在说什么

一句话：纯软件（个人和企业）很难再建立起优势。

底下的情绪很清楚——实现门槛塌了，付费理由也在塌。有人附和：人人都能做，潜意识里就觉得不值得付钱。

## 社区共识：先分层，别一刀切

讨论区并不买「所有软件都不值钱」，但高频信号很齐：

| 更容易贬值 | 更难立刻贬值 |
| --- | --- |
| 工具小应用、清理/设置壳、细分信息站 | 行业软件、工业仿真、长期专业产品 |
| 本地、依赖少、容错高的个人功能 | 大规模云服务 + 资质门槛 |
| 「一天能做一百个」的壳 | 长时间堆出来的体验与边界条件 |

可带走的句：**大模型能力就是斩杀线**——人人都能写的不值钱；复杂、可靠、有场景的仍值钱。

也有人提醒：值钱的从来是产品与服务，不是「代码文件」本身。软硬件结合、B 端生产环境打磨、持续维护意愿，都会把壁垒往代码外面推。

![斩杀线上下分层](../../assets/inline-software-not-valuable-ai-era-02.jpg)

## 「人人会做饭还下馆子」为什么对软件不好使

反驳帖主的人爱用这句类比。反方戳破关键差异：吃饭是硬需求；大量软件不是。馆子还解决不想做、做不好、聚会仪式感——软件却常常可以被「临时 vibe 一个」替代。

真正还能对标的，只剩愿意为**稳定、品味、省心、信任**付钱的那一层。那已经不是在买代码，是在买结果。

## 护城河迁到哪

社区几乎同向：

- 业务与运营 > 代码  
- 数据 + 工作流 + 信任 + 领域深度 + 持续学习，替换功能堆砌  
- 长期维护反而更稀缺：做变容易后，坚持维护的人更少  
- 可能的新商机：软件发现、评测、二次开发、API 组合——规模效应仍在，不必人人从头 vibe

财报派也会泼冷水：专业软件与 AI 软件股仍在涨。说「不值钱」时，别把**边缘工具商品化**说成全行业归零。

## 我方终局：定制也会贬值

社区多数还在争「现在贬不贬」。对我更有用的是终局分层：

1. **功能层**：记账、翻译、常规 CRUD、普通官网——默认能力吞掉。  
2. **定制层**：项目制改需求会被对话制 Agent 改需求压缩，毛利塌陷。  
3. **仍可能值钱**：持续运营的成果与背锅责任；帮用户选对并管住安全合规的分发信任；换 Agent 也带不走的专有数据与工作流记忆；物理世界、资质、供应链。

创业含义很直接：少卖「又一个 App / 又一次定制」；多卖 Agent 可用的 capabilities、编排、SLA，以及「伪装成服务的软件公司」——对照 [[lovable-future-saas-agent-capabilities|未来 SaaS 是 Agent 可用能力]] 与 [[software-engineering-splits-three|软件工程在拆成三条路]]。

## 决策清单

1. 这是斩杀线以下的功能吗？是就别当独立付费软件押宝。  
2. 若卖定制：假设客户明年用 Agent 自助改，你的报价还成立吗？  
3. 优先堆业务闭环、数据飞轮、工作流记忆、硬件/资质、可证明的维护与责任。  
4. 叙事从「我有功能」改成「我交付结果，并在模型升级时变得更便宜」。

代码变便宜，不等于价值消失——**价值只是离开了「实现」和「改需求」本身。**
