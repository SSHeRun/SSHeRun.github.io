Anthropic 给 Claude 加了一条很短的规矩，大意是：可以做原创游戏、类型游戏、用户自有设计；**不要**复刻某个已存在的具体游戏——就算你改名、自称原创也不行。

官方解释很体面：用 Claude 侵犯 IP 违反使用政策。社区的反应更难听一截：**所以你们终于开始在乎知识产权了？——选择性地。**

来源讨论：[r/technology 帖](https://www.reddit.com/r/technology/comments/1xl7omq/anthropic_adds_new_claude_rule_banning/)（约 5.5k↑）

## 双标长什么样

![Claude 的双标：训练时吞版权，输出时护大厂游戏概览](../../assets/inline-claude-ip-double-standard-01.jpg)

高赞几乎同构：

1. **训练侧**：几乎把地球上能爬到的受版权文本吞进模型，再拿去卖订阅。  
2. **输出侧**：用户说「做个像某某的游戏」就被系统提示词拦住。  
3. **触发条件**：有人直说——影响到索尼、迪士尼利润线时，版权才突然变成原则。

「他们可以偷我的图，公司产品却必须被保护」——这不是法律意见书，是情绪判决。但情绪对准的是真实不对称：**个人与小工作室的作品被当饲料；平台级 IP 被写进模型行为约束。**

## 禁令有多「原则」

两个观察让「我们很尊重版权」听起来像公关：

**容易绕过。** 有人写：让另一个模型根据原作先吐一份设计文档，再喂给 Claude；或「方块下落、消行，完全是我的创意」。规则拦的是懒提示词，不是意图。

**误伤正当需求。** 媒体后来报道，规则一度连「点名某作来描述机制」都误杀；Anthropic 又改成允许 similar mechanics， outright copy 则改推「同类型原创」。第一刀更像急刹车，第二刀才是产品补丁——原则若清晰，不该靠用户骂完再 diff。

还有人抱怨：封闭模型可以无限加规则；安全/防御向的代码讨论也被同类监控搞废。游戏只是这次露出来的那一根栏杆。

## 真正的议题不是「游戏该不该被克隆」

![Claude 的双标：训练时吞版权，输出时护大厂游戏细节](../../assets/inline-claude-ip-double-standard-02.jpg)

独立游戏被 AI 快速换皮、甚至被拿去要挟，是真问题。厂商想挡「一键复刻 GTA」也说得通。

但若把叙事停在「Anthropic 保护创作者」，就漏了权力结构：

- **谁的版权**进入系统提示词级别的硬约束  
- **谁的版权**只配在训练数据争议里当脚注  
- **谁**在「先偷再道歉，只向告得起的人道歉」的循环里（楼内原话味道）

闭源助手越强，规则列表越像新的 EULA：不是宪法，是运营手册。手册写给投资者和诉讼风险看，不写给你的公平感看。

## 对我有用的三件事

1. **当产品信号**：条款变化优先服务「可被起诉的大 IP + 可被刷屏的滥用场景」，别期待普遍主义版权伦理。  
2. **当工程依赖**：关键工作流绑死单一闭源模型，等于接受对方随时加两句话改你的能力边界。  
3. **当创作者策略**：保护自己的办法仍是分发、社区与法律组合拳；别指望训练你作品的那家公司，会在推理层对你和对迪士尼一视同仁。

Claude 可以不做俄罗斯方块复刻版。更值得盯的是：同样一套「尊重 IP」的话术，在训练日志和系统提示词里，到底对谁生效。
