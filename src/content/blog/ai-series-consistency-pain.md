> 讨论来源：[How I'm handling character + scene consistency…](https://www.reddit.com/r/aivideomaking/comments/1xo7upe/how_im_handling_character_scene_consistency/)（r/aivideomaking，约 50↑ / 32 评）

做一条 8 秒 AI 短片，大家比的是「好不好看」。  
做一集、一部——哪怕只是同城连拍——比的立刻变成另一件事：**上一镜还是那张脸吗？房间里的灯还在原来的位置吗？**

r/aivideomaking 有人把一整套「长片级」做法摊开：56 个角色、87 个地点、115 件道具，围绕 Metropolis 气质的世界搭建。楼里吵细节，但痛点高度重合——**AI 做剧集，最大的坑不是不会生成，是生成完对不上号。**

## 痛点到底是什么

![角色与场景在镜头间漂移](../../assets/inline-ai-series-consistency-pain-01.jpg)

短视频可以靠好运气：抽中一张图、再延一镜。  
剧集不行。同一角色要在远景、近景、背影、情绪特写里反复出现；同一房间要在正反打、日夜态、火灾态里还像「那个地方」。模型一旦「发明」——墙上多一幅画、桌上换一盒麦片、脸在全景里糊成别人——观众立刻出戏。

楼里一句说透了：

> 把连续性当成结构化的空间数据（镜头 → 3D 舞台 → 物理镜头 → 校验静帧 → 视频），而不是用文案提示词去赌。

这就是和「会写 prompt」的分水岭。prompt 管的是单次审美；剧集要的是**跨镜可复用的身份与地理。**

## 楼主那套流水线（可记的骨架）

![从 clay 到视频的分层](../../assets/inline-ai-series-consistency-pain-02.jpg)

核心不是某个神模型，而是分层资产 + 按镜头取用：

1. **故事数据当脊椎**：每个镜头写清谁在干什么、什么情绪；后面的表情库、构图强调都从这里长出来。  
2. **角色参考拆开用**：不是一张万能角色表糊全部。广角优先全身（衣服、发型、体型），近景优先脸；表情从中性头像用物理描述（眉、睑、嘴、颌、目光）改出来，而不是只写「sad」。  
3. **场景用 plate，而不是复述房间**：每个地点留建立镜头；prompt 侧重动作，不把房间再描述一遍——文字会漂，帧不会。更狠一点：把相机解算和 plate 做空间索引，裁出「这台相机实际看见的那一块」，减少模型从整屋乱抽细节。  
4. **3D clay / 高保真布景当几何约束**：灰盒让图像模型每镜重画陈设；高保真 Blender / 高斯泼溅 / Hero Props 把「该在那儿的东西」钉死。有人发现：中间那张「电影感静帧」如果先发明了背景，再喂给视频，漂移会更糟——有时不如 animatic / plate 直通视频。  
5. **Agent 当工装，不是当导演**：一级做、一级审，创意决定留给人。OP 说一致性那侧已经可规模化；他真正盯的是**情绪有没有出来**——一致但死气沉沉，也不算赢。

规模感也写进了帖子：角色参考约 500 张、地点状态 85、3D 布景 61……新故事要重做数据与资产，**可带走的是工作流，不是那一套 Metropolis 贴图。**

## 楼里补刀的实操共识

![全景糊脸与每镜三件套](../../assets/inline-ai-series-consistency-pain-03.jpg)

- **脸小、侧过、远景最容易丢锁**：预算留给这里重渲；真要认脸就切近，广角认的是衣服和发型。  
- **每镜记三样：reference / seed / prompt**——错了才知道动了哪根线。  
- **群戏单独建参考组**，整场戏定人数、队形、进出，不要每镜重排，否则人群会「瞬移」。  
- **灯光状态做成环境变体**（日 / 夜 / 着火），而不是指望灰泥模型每次自己悟。  
- **假人骨架管姿态，角色表管形貌**：深度/Canny 锁太死，人会变成假人比例；姿态意图与身份权威要拆开。

也有人提醒：别把整篇长文丢给 LLM 再发帖——但流水线本身，是真问题真解法。

## 我怎么看

「AI 制作剧集最大的痛点」如果缩成一句：

**不是分辨率，是跨镜头的身份连续性；不是再找一个更强的文生视频，是先把角色、场景、相机解算做成可索引资产。**

短视频时代我们习惯「一次生成、一次惊喜」。剧集时代要改习惯：先工程师后导演——把 Tedious 的一致性做可规模化，才轮得到在 previs 里玩类型、构图和情绪。楼主赌的是：这套站住，整片 keepers 成本有机会压到一千美元量级；楼里真正有价值的，是那句——**赌 prompt 做不出叙事长片，做空间数据才有机会。**
